# UZCARD Mini Project — Tranzaksiyalar tahlili

## Loyiha haqida

Ushbu loyihani yozda UZCARD Academy’da o‘qish davomida bajarganman. Loyihada bank tranzaksiyalariga oid ma’lumotlarni tahlil qilib, to‘lovlar qanday amalga oshirilishi, nima sababdan ayrim tranzaksiyalar rad etilishi va merchantlar aylanmasi qanday taqsimlanganini o‘rgandim.

Loyiha davomida SQL va Python yordamida ma’lumotlar bilan ishladim, turli tahlillar o‘tkazdim va natijalarni grafiklar orqali ko‘rsatdim.

## Loyihada nimalar qildim?

- Rad etilgan tranzaksiyalarni tahlil qildim.
- To‘lovlar nima sababdan rad etilishini o‘rgandim.
- Turli merchant kategoriyalaridagi bahsli tranzaksiyalarni taqqosladim.
- Tranzaksiya vaqti va to‘lov usulining natijalarga ta’sirini ko‘rib chiqdim.
- Merchantlar o‘rtasida umumiy aylanma qanday taqsimlanganini tahlil qildim.
- Lorenz egri chizig‘i va Gini koeffitsiyenti yordamida aylanmadagi farqlarni o‘rgandim.

## Foydalanilgan texnologiyalar

- Python
- Pandas va NumPy
- Matplotlib va Seaborn
- SQL va PostgreSQL
- Jupyter Notebook

## Loyiha davomida olgan tajribam

Bu loyiha orqali SQL va Python bo‘yicha bilimlarimni amaliyotda qo‘llash imkoniga ega bo‘ldim. Ma’lumotlarni tozalash, tahlil qilish, grafiklar yaratish va natijalardan xulosa chiqarish bo‘yicha tajribamni oshirdim.

Shuningdek, moliyaviy ma’lumotlar bilan ishlash va ularning ichidagi muhim bog‘liqliklarni aniqlashni o‘rgandim.
